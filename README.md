# Clash Meta / mihomo 控制台 (Mihomo Dashboard)

一款基于 **React 19 + TypeScript + Vite** 构建的高颜值、高性能、高信息密度的 Clash Meta (mihomo) 现代化 Web 控制台。

视觉风格深度对齐“清新版工作台 (Fresh Workbench)”原生设计规范（见 `DESIGN.md` 与 `demo.jpeg`）：全屏通铺浅薄荷绿 `#F0F6F2` 至淡薰衣草紫 `#F0EEF8` 流动渐变主画布、高透磨砂玻璃材质、顶部紧凑横向导航与深黑活动胶囊、双分段配比条带、纯白实心微投影圆形动作按钮、等宽数字微排版以及 42:58 不对称工作台布局。

> 当前 Overview 的实现顺序及旧布局覆盖关系以 [`DESIGN.md`](./DESIGN.md) 顶部“当前 Overview 布局覆盖说明”为准。规则链路流向的节点、交互和视觉处理参考并改编自 Neko Master（MIT）；许可文本见 [`NEKO-LICENSE`](./NEKO-LICENSE)。

## 核心功能与页面结构

1. **总览 (Overview - 清新工作台)**
   - **紧凑顶部横向导航**：Mihomo 品牌徽标、横向导航胶囊（总览默认为深黑高质感活动胶囊）、运行模式快速切片（规则/全局/直连）、演示预览开关、连接状态指示与纯白圆形动作按钮组（刷新、设置）。
   - **内核大标题与行内元数据横幅**：28px 加粗主标题 `Mihomo Core` + 真实版本模式胶囊，横向对齐展示 5 列真实运行时元数据（核心版本、运行模式、控制端点、混合端口、生效规则），严格遵循真实 API，杜绝推断捏造。
   - **双分段色彩与花纹配比进度条带**：
     - **出站链路配比条带**：依据当前活动连接动态聚合链路占比（多色切片条带），空载时诚实显示中性单轨；下方显示 32px 大字号实时下行速率（`↓ 24.85 MB/s`）、累计下载量与精确到秒的时间微排版。
     - **传输协议配比条带**：依据真实 TCP 与 UDP 连接数动态聚合比例，应用碳黑圆点与灰调斜纹质感花纹；下方显示 32px 大字号系统内存占用（`128.45 MB`）与系统物理上限，严格杜绝虚构 Goroutines 或假 DNS 切片；右上角配备一键断开全部连接按钮（带二次确认安全防护）。
   - **纤细横向渐变分隔线**：1px 细线优雅衔接上下板块。
   - **下层 42:58 不对称双主栏**：
     - **左主栏（42% Deal History 风格策略组）**：紧凑策略组卡片，左侧大号奶油色延迟药丸胶囊（`⚡ 32 ms`）与微排版元数据（类型、节点数），右侧圆形地区国旗头像（🇭🇰/🇯🇵等）、选中节点名、真实传输协议类型（`Hysteria2`/`Shadowsocks`等），配独立的纯白圆形测速（`⚡`）与节点切换（`⇄`）动作按钮。
     - **右主栏（58% 4 宫格系统卡片与高密度连接表）**：顶部 4 宫格展示真实运行模式、监听端口、生效规则与活跃连接数；下方承接高密度实时网络连接追踪表，采用亮蓝色域名超链接、进程链路、等宽时间戳与单连接乐观断开。

2. **代理节点 (Proxies)**
   - 全局运行模式胶囊切换：`规则模式 (rule)` / `全局模式 (global)` / `直连模式 (direct)`（通过 `PATCH /configs` 实现）。
   - 节点多维排序：支持按默认配置顺序、延迟从低到高、节点名称字母排序。
   - 节点批量测速与单节点延迟测试（`GET /proxies/:name/delay`，带 URL 编码与超时控制）。
   - 策略组与自选区分：非 Selector 组（如 URLTest、Fallback）明确提示由算法自动调度，防止误操作。

3. **活动连接 (Connections)**
   - 动态长连接/短连接列表：目标地址、端口、网络协议（TCP/UDP）、分流命中规则、代理链路追溯（如 `国外媒体 → 香港 01`）、已传输流量与耗时。
   - 交互操作：单条连接精准断开（`DELETE /connections/:id`）、全量连接批量断开确认弹窗（`DELETE /connections`）。
   - 深度元数据抽屉：点击任意行展开完整的网络元数据（源 IP/端口、目标 IP/端口、发起进程绝对路径、入站协议等）。

4. **实时日志 (Logs)**
   - WebSocket 实时流：通过 `ws://.../logs?level=info` 持续接收内核日志（支持 debug / info / warning / error 等级动态调整）。
   - 控制工具：关键词实时搜索过滤、跟随滚动 / 暂停日志（暂停时显示新未读数量计数 `+N`）、一键复制选中日志、清空控制台。

5. **分流规则 (Rules)**
   - 完整加载 mihomo 核心配置中的规则集（`GET /rules`）。
   - 支持按规则类型快速筛选（`DOMAIN-SUFFIX`、`DOMAIN-KEYWORD`、`IP-CIDR`、`GEOIP`、`MATCH` 等）以及载荷与策略组模糊搜索。

6. **控制器配置与排障 (Config & Settings)**
   - **外部控制器连接配置**：可自定义控制器 API 基础地址（默认 `http://127.0.0.1:9090`）与访问密钥 (Secret)。
   - **凭据安全设计**：Controller Secret 仅在当前标签页会话的内存及 `sessionStorage` 中暂存，**绝不写入持久化 `localStorage`**，杜绝凭据泄漏隐患。
   - **CORS 与 Mixed Content 排障指引**：内置详细的跨域及 HTTPS 页面请求 HTTP 本地控制器的原理说明与解决方案。
   - **运行时参数调整**：支持动态调整 `mode`、`log-level`、`allow-lan`，并直观查看 Mixed/HTTP/SOCKS5/Redir/TProxy 监听端口。
   - **规范说明**：明确标明 Mihomo REST API 仅提供运行时参数动态调控接口，不提供全量 YAML 文件在线覆写接口，避免误导。

7. **仿真演示模式 (Demo Preview Mode)**
   - 界面内置完整丰富且逼真的仿真数据集（包含版本信息、多策略组、各协议节点、活跃网络请求、动态流量波形、实时日志等）。
   - 随时可通过顶部导航栏的 **「演示预览」** 按钮一键切换，无需启动本地核心即可完整体验所有页面布局、测速、节点切换等交互流程。
   - 演示模式带有显式 `【仿真】` 与琥珀高亮提示，绝不与真实在线连接混淆；切换退出演示模式时具备严格的端点探测保全机制，探测失败保持仿真态，不提交未验证凭据。

## 本地启动与构建

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```
打开浏览器访问 [http://localhost:3000](http://localhost:3000)。

### 3. 运行单元测试
```bash
npm test
```
包含针对 API 请求封装、URL 与 WebSocket 拼接、Token 鉴权、数据换算（Bytes/Speed/Duration/Latency）、出站链路与协议配比聚合计算、节点国旗匹配以及代理排序与连接过滤的自动化单元测试。

### 4. 生产打包构建
```bash
npm run build
```
输出纯静态文件至 `dist/` 目录。

## 技术架构

- **框架**：React 19 + TypeScript + Vite 6
- **图标**：Lucide React
- **测试框架**：Vitest 3
- **通信通道**：
  - HTTP REST：`GET /version`、`GET/PATCH /configs`、`GET/PUT /proxies`、`GET /rules`、`GET/DELETE /connections`
  - WebSocket：`WS /traffic`（流量动态采样）、`WS /memory`（内存占用采样）、`WS /connections`（连接实时追踪）、`WS /logs`（日志无限流）
- **样式**：现代化原生 CSS（采用 CSS Variables 统一设计令牌与磨砂玻璃体系，纯 CSS 生成斜纹与点阵质感，极致轻巧灵动）。
