# Circular Flag SVGs

The circular flag SVGs in this directory are sourced from [HatScripts/circle-flags](https://github.com/HatScripts/circle-flags), licensed under the MIT License.

## Included Region Codes
- `hk.svg`: Hong Kong (HK / HKG)
- `sg.svg`: Singapore (SG / SIN)
- `us.svg`: United States (US / USA / LAX)
- `jp.svg`: Japan (JP / JPN / TYO)
- `tw.svg`: Taiwan (TW / TWN)
- `kr.svg`: South Korea (KR / KOR / SEL)
- `gb.svg`: United Kingdom (GB / UK)
- `de.svg`: Germany (DE / DEU / FRA)
- `ca.svg`: Canada (CA / CAN)
- `au.svg`: Australia (AU / AUS / SYD)
